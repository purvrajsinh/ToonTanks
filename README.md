## 🕹️ About

**ToonTanks** is a tank-based game developed in Unreal Engine, featuring stylized environments, tank combat, projectile mechanics, enemy turrets, and gameplay systems built using C++ and Unreal Engine.

## ✨ Features

* 🚀 Tank movement and controls
* 🎯 Projectile firing system
* 💥 Tank and turret combat
* 🤖 Enemy turret AI
* ❤️ Health and damage system
* 🏆 Win/Lose gameplay conditions
* 🌍 Stylized 3D environment
* 🎮 Unreal Engine gameplay framework

## 🛠️ Built With

* **Unreal Engine**
* **C++**
* **Blueprints**
* **Visual Studio**
* **Git / GitHub**

## 📂 Project Structure

```text
ToonTanks/
├── Config/
├── Content/
├── Source/
├── ToonTanks.uproject
└── README.md
```

Generated Unreal Engine folders such as `Binaries`, `Intermediate`, `Saved`, and `DerivedDataCache` are excluded from the repository using `.gitignore`.

## 🚀 Getting Started

### Prerequisites

* Unreal Engine
* Visual Studio with the required C++ development tools
* Git

### Clone the Repository

```bash
git clone https://github.com/purvrajsinh/ToonTanks.git
```

Open the project:

```text
ToonTanks.uproject
```

Generate Visual Studio project files if required, then build and launch the project through Unreal Engine.
